# Vantaframe Studio

Portfolio website for Vantaframe Studio — an AI advertising creative studio.

## Edit before publishing
1. Open `index.html`.
2. Replace the placeholder WhatsApp number in the contact link with the studio's real WhatsApp number.
3. Replace the visual placeholders in the Work section with real portfolio images/videos as projects are completed.

## Tech
Plain HTML, CSS and JavaScript. No build step required.
